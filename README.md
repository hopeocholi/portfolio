# Hope Ocholi | Interactive Project Portfolio

**Live site: [hopeocholi.github.io/portfolio](https://hopeocholi.github.io/portfolio/)**

An interactive portfolio for my work as a Technical Project Manager in Dublin. The opening scene is a 3D delivery network: each bright node is a project, payments flow along the connections, and selecting a node takes you to that project's case study.

## What's inside

- **Seven projects** across cloud migration, network deployment, vendor and budget governance, payments and financial reporting, with filters by domain.
- **Project Tidewatch**, a full project file for a graph-enhanced AML monitoring programme: a 20-week schedule with seven stage gates, a clickable risk heat map, the budget breakdown, success criteria and an honest build status. Tidewatch is a portfolio simulation on public, synthetic data, and the page says so.
- **How I work**: the four habits behind every project, from baselining to acceptance.
- **Credentials**: PMP, PRINCE2 Practitioner, AZ-104, SAFe POPM, ITIL 4, PSM I and PSPO I; MSc in FinTech (First Class Honours).

## Built with

One self-contained HTML file: [three.js](https://threejs.org/) for the 3D scene, hand-written CSS and JavaScript for everything else. It adapts to light and dark mode, works on phones, and respects reduced-motion settings.
